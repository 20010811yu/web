# 网站优化实施计划（SEO 基础包 + 体验增强包 + 内容细节包）

## 一、SEO 基础包
1. **每路由独立 title/description**：新建 `src/seo.js`（页面名 → 中英 title/description 映射），router `afterEach` 中按当前语言设置 `document.title` 与 meta description；语言切换时同步刷新
2. **index.html 默认 meta**：补 description/keywords/OG 基础标签（og:title/description/type/url，og:image 用厂房 Hero 图）
3. **语言切换联动**：`setLocale` 时更新 `<html lang>` 与当前页 title/description（now setLocale only sets lang）
4. **`public/sitemap.xml` + `public/robots.txt`**（7 条路由；域名上线后替换 host）
5. **Organization 结构化数据**（JSON-LD：公司名、logo、联系方式、地址）注入 index.html

## 二、体验增强包
6. **移动端底部悬浮联系栏**（≤768px 显示）：电话（tel: 拨号）｜微信（弹二维码弹层）｜询盘（跳联系页）——新建 `MobileContactBar.vue` 挂 App.vue
7. **滚动进入动效**：自定义 `v-reveal` 指令（IntersectionObserver，进入视口淡入+上移 12px），全局注册并给各页 section/卡片补指令；`prefers-reduced-motion` 时禁用
8. **返回顶部按钮**：新建 `BackTop.vue`（滚动超一屏显示，右下角，移动端联系栏上方）

## 三、内容细节包
9. **新闻上一篇/下一篇**：NewsDetail.vue 底部加相邻文章导航
10. **图片 WebP**：产品/新闻/关于图转 WebP（Pillow 不可用，用 jimp 转？jimp 0.22 不支持 webp 编码——改用 cwebp？无。备选：用 `sharp`（npm 原生包，Windows 可安装）批量转换 + `<picture>` 或直接替换引用；若 sharp 安装失败则跳过并记录）
11. **hero 图预加载**：index.html 加 `<link rel="preload">`

## 收尾
`npm run build` 验证 → 记忆库同步（systemPatterns 记 SEO/动效模式）→ 自动推送 GitHub。
