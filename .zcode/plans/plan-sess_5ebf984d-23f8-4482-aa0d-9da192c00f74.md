# 修复合作伙伴 logo 白框

## 原因
WebP 批量转换时 partner-01.png 被删（转出的 webp 与原 PNG 同为 4K，脚本误判为"更小"保留），而 `src/data/index.js` 引用的是 `partner-01.png` → 404 白框。

## 修复
1. 从旧站 OSS 重新下载 `images/logo/1.png` 覆盖恢复 `public/images/partners/partner-01.png`，删除多余的 partner-01.webp
2. 防复发：将 webp 转换脚本的替换条件收紧为「webp 体积 < 原图 90%」才替换（避免此类微小差异误替换）——本次仅恢复文件即可，不重跑转换
3. `npm run build` 验证 → 提交推送

## 顺手加固
在 towebp.js 思路基础上，把「伙伴 logo 目录」加入转换排除清单（小图标转换收益为零），避免以后再跑转换时误伤。
