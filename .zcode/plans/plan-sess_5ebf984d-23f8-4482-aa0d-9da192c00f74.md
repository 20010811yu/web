# 合作伙伴栏修复 + 全站字体放大

## 1. 合作伙伴栏修复（Home.vue 样式）
- 删除 grayscale 滤镜与半透明 → logo 任何情况下彩色显示
- 网格列改 `repeat(5, minmax(0,1fr))`、`.partner` 加 `overflow:hidden`、img 明确尺寸约束——修复 logo 撑破网格导致整体偏右/右列被裁切的问题；移动端断点同步

## 2. 全站字体放大
- 根字号基准从 `clamp(12px, 0.8333vw, 20px)`（1920→16px）提高为 `clamp(13px, 0.9375vw, 22px)`（1920→18px，约 +12.5%）
- 全站尺寸均基于 rem，根字号放大即全站文字、图标、Element Plus 组件字体等比放大，弹性缩放特性保持
- 标题 token 微调：font-xl 1.625→1.75rem，font-2xl 2.25→2.5rem，font-hero 3.25→3.5rem（移动端断点同步 +）

## 3. 收尾
`npm run build` 验证 → 记忆库同步 → 自动推送 GitHub
