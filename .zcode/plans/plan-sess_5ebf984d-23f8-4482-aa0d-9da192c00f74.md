# 产品型号归类展示改造

## 需求
一个产品线下有多个型号（如铝型材线有 YK-7A/7B/7W 三种），目前参数表是纵向全部堆叠展示。改为**归类选择式**：型号以子标签（el-tabs 或按钮组）切换，一次只展示一个型号的参数。

## 实施（仅改 Products.vue 展示层，params.js 数据结构不动）
1. 在"技术参数"区标题下加型号切换条（按钮组样式与左侧产品导航一致；单型号的产品线如上料机不显示切换条）
2. 新增 `activeModel` 状态（切换产品线时自动重置为该线第一个型号），仅渲染当前选中型号的参数表
3. 型号切换条文字 = 型号名 + 中文副标题（双语）
4. `npm run build` 验证 → 记忆库同步 → 自动推送 GitHub
