# 寅铠官网改版设计与实施计划（Vue 3 + Element Plus，深色工业科技风 + 弹性缩放布局）

## 定位
对 http://www.yinkaish.com/cn/ 的全面改版：上海寅铠精密机械——光伏边框自动化设备制造商。真实内容替换占位数据，深色工业科技风，中英双语等权，**全站弹性缩放布局**。不设团队/领导层页面。

## 弹性布局方案（新增核心需求）

采用 **rem 基准 + 视口联动缩放** 方案，实现窗口缩放时字体、图片、图标、间距等比缩放：

1. **根字号联动**：`html { font-size: clamp(12px, 0.833vw, 20px) }`（以 1920 设计稿 16px 为基准，随视口宽度线性缩放，设上下限防止过小/过大）
2. **全站尺寸单位**：字体、间距、圆角、组件尺寸一律用 `rem`；图片/图标容器用 `rem` 或百分比宽度 + `aspect-ratio` 固定比例
3. **图标**：Element Plus 图标与 SVG 图标尺寸用 rem（`em` 相对字号），随文字同步缩放
4. **断点兜底**：≤768px 切换移动端布局（单列堆叠），此时根字号改用固定较小值而非继续压缩
5. **Element Plus 适配**：覆盖其组件尺寸变量（`--el-font-size-base` 等）为 rem，保证表格/表单/按钮同步缩放
6. **design tokens**：所有间距/字号定义 `--space-*` / `--font-*` 的 rem 变量，组件只引用变量

验收标准：缩放窗口宽度时页面元素平滑等比缩放无跳变；1920/1440/1024/768 宽度下布局均正常。

## 设计规范

**品牌视觉（design tokens）**
- 背景：石墨黑/深海军蓝分层（#0d1520 系，卡片浮层递进提亮）
- 强调色：能源绿/科技蓝（`--el-color-primary` 覆盖）
- 质感元素：细线描边、渐变光晕、数据大数字、SVG 线条装饰

**首页模块顺序**
1. Hero：全幅车间实拍大图 + 价值主张"光伏边框自动化整线解决方案" + 数据条（20+ 年 / 7 代设备 / 节拍 ≤2s）
2. 核心业务三卡片：自动生产线 / 码垛·上料 / 视觉检测
3. 关于速览：资质徽章墙（ISO9001、高企、专精特新）
4. 发展历程：横向交互时间线（2004–2024 七代设备）
5. 合作伙伴 logo 滚动墙
6. 新闻三则速览
7. CTA 条：询盘/联系

## 页面规划（6 个页面视图 + 新闻详情）
1. 首页
2. 产品与服务：产品线 + 标准模板（场景图 + 参数表 el-table + 优势 + 在线询盘）
3. 关于寅铠：简介、资质、发展历程（el-timeline）
4. 企业动态：新闻列表 + 详情页
5. 联系我们：联系方式 + el-form 表单 + 地图占位
6. 招贤纳士：福利 + 职位列表（el-collapse）

## 实施步骤
1. P1 落档：更新 memory-bank（projectbrief 寅铠改版定位 + 弹性布局决策入 systemPatterns，activeContext 写计划）
2. S2 脚手架：Vite + Vue3 + Router + vue-i18n + Element Plus 按需引入
3. S3 基础：弹性缩放方案（rem 基准 + clamp + EP 变量适配）+ design tokens + 深色主题 + Navbar/Footer/PageHero + i18n
4. S4 数据：参考站内容整理为双语 data 文件（products/history/partners/news/jobs）
5. S5 页面：逐页实现，每页完成后在多宽度下自查缩放表现
6. P3 验证：build + 双语 + 1920/1440/1024/768 缩放自查 → pre-commit-check 自动推送 GitHub
