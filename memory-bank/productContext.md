# 产品上下文（Product Context）

> 记忆库「为什么」。解决什么问题、应如何工作、用户体验目标。仅在需求语义变化且经用户确认后更新。

## 解决什么问题

公司需要一个对外的统一线上门面：向访客（客户、求职者、合作伙伴）清晰传达公司是谁、做什么、有什么优势，并提供联系与加入入口。

## 目标用户

1. **潜在客户/合作伙伴**：了解业务能力 → 联系我们
2. **求职者**：了解团队与文化 → 查看职位 → 投递/联系
3. **媒体/公众**：获取公司动态

## 应如何工作

- 单页应用，7 个页面经 Vue Router 导航；导航栏全局可见
- 中英切换按钮位于导航栏，切换即时生效、刷新保持（localStorage）
- 移动端汉堡菜单；全站响应式
- 所有内容先用占位数据（示例公司），结构保证后续文案替换即可上线

## 体验目标

- 首屏快速加载（按需引入、无全量 UI 库）
- 视觉现代简洁、品牌色统一
- 中英文案同等完整，不出现缺翻译
