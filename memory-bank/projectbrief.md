# 项目概要（Project Brief）

> 记忆库「事实来源」。定义核心需求、目标与范围边界。仅在范围/目标/阶段描述真实变化时更新（P4）。

## 项目定位

公司官方网站：对外展示公司形象、业务与团队的中英双语响应式网站。

## 目标

1. 提供 7 个核心页面：首页、关于我们、业务/产品、团队、新闻动态（列表+详情）、联系我们、加入我们
2. 中英双语全站覆盖，语言切换即时生效并持久化偏好
3. 桌面/平板/手机三档响应式布局
4. 视觉现代简洁，体现品牌定制感

## 技术选型（已确认）

Vue 3 + Vite + Vue Router 4 + vue-i18n 9 + Element Plus（按需引入 + 自定义主题色），原生 CSS design tokens。

## 范围边界（本次不做）

- 真实域名部署与 CI/CD
- 后端接口对接（表单提交为前端模拟）
- SEO 深度优化、SSR
