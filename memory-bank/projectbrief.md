# 项目概要（Project Brief）

> 记忆库「事实来源」。定义核心需求、目标与范围边界。仅在范围/目标/阶段描述真实变化时更新（P4）。

## 项目定位

**上海寅铠精密机械官网改版**（参考旧站 http://www.yinkaish.com/cn/ ）：光伏边框自动化设备制造商的对外官网，深色工业科技风，中英双语，全站弹性缩放布局。真实内容（历程、产品、资质、伙伴）来自旧站，缺失信息用占位并标 TODO。

## 目标

1. 6 个页面视图 + 新闻详情：首页、产品与服务、关于寅铠、企业动态（列表+详情）、联系我们、招贤纳士。**不设团队/领导层页面**
2. 中英双语全站覆盖，切换即时生效并持久化偏好
3. **弹性缩放布局**：缩放窗口时字体、图片、图标、间距等比缩放（rem 基准 + clamp 视口联动，≤768px 切移动布局）
4. 深色工业科技风：石墨黑分层背景 + 能源绿/科技蓝强调色
5. 产品页标准模板：场景图 + 参数表 + 优势 + 在线询盘（补齐旧站短板）

## 技术选型（已确认）

Vue 3 + Vite + Vue Router 4 + vue-i18n 9 + Element Plus（按需引入 + CSS 变量主题覆盖 + 尺寸变量 rem 适配），原生 CSS design tokens。

## 范围边界（本次不做）

- 真实域名部署与 CI/CD
- 后端接口对接（表单提交为前端模拟）
- SEO 深度优化、SSR
- 产品真实参数（旧站缺失，占位 + TODO 待用户提供）
- 团队/领导层内容（用户确认不需要）
